# Flute sound library

Reusable bansuri EQ, reverb, ambience, and recording setup settings. Keep this repository private in the personal GitHub account.

| Sound | Instrument / microphone | Status |
| --- | --- | --- |
| [Middle Flute Airy](<Sound Library/Middle Flute Airy/README.md>) | C# middle bansuri / beyerdynamic M160 | Approved from take #03 on 2026-10-07 |

Each sound includes a native GarageBand patch, readable recall instructions, machine-readable settings, and patch checksums. The native patch preserves the full saved plug-in state; the settings file records the controls we verified.

Recordings, tracks, GarageBand projects, accompaniment, exports, reference audio, and audio-processing work files stay local and are excluded by the default-deny `.gitignore`. No audio is part of this library.

On this Mac, the complete prior studio guide remains in [Studio Guide (local).md](<Studio Guide (local).md>). That guide is intentionally untracked, so this link is available only in the local folder.

For a new accepted sound, save a distinctly named GarageBand User Patch, add a settings entry, verify it, then commit and push the settings-only changes. Preserve previous accepted sounds and use Git history for revisions.
